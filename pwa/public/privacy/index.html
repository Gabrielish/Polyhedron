Privacy Policy

What Polyhedron accesses, why it needs it, and how you stay in control.

Last updated: October 6, 2026

1. Who we are

Polyhedron is an independent game-translation tool maintained by Gabrielish. This policy covers the desktop application, this website and its browser companion. Contact: gabrielbundea1@gmail.com.

Core desktop editing does not require a Google account. Google Drive and external translation services are optional. Polyhedron does not operate a developer-hosted server that stores your translation workspaces.

2. Data we use

  • Translation projects: files you open or import, source and translated text, content IDs, project names, review information, history, glossary entries and preferences.
  • Credentials: provider API keys you enter and OAuth tokens issued by Google when you authorize Drive access. Polyhedron never asks for your Google password.
  • Google account information: the desktop Drive connection may display your name, email address and profile picture returned by Google.
  • Diagnostics and contact: local error logs may contain file paths and technical details. If you contact the maintainer, the maintainer receives what you send, including your email address and any attachments. Do not send API keys, passwords or tokens.

This website is hosted by GitHub Pages. Hosting and external services may receive ordinary connection information, such as your IP address and browser details, under their own privacy policies.

3. Google Drive access

When you connect Google Drive, Polyhedron communicates with Google to locate, download, create or update its workspace backups, synchronization files and glossary files. These can contain translation text and project information. Their purpose is to let you back up work and continue it across your own devices.

Permissions differ by client

  • Desktop: requests https://www.googleapis.com/auth/drive.file, which limits access to files created by, opened with, or otherwise made available to the app.
  • Browser companion: currently requests https://www.googleapis.com/auth/drive. This is a broader permission that can allow access to all Drive files. The companion uses it to find, read and update polyhedron-workspace-sync.json created by the desktop application; its implemented sync features do not browse or use unrelated file contents.

Review Google's consent screen before authorizing access. Connecting Drive does not send your Google password or Drive authorization to the project maintainer.

Google user data is used for the translation and synchronization features you choose. Polyhedron does not sell it, use it for advertising, or use it to train generalized AI models. The maintainer does not routinely access your private Drive files. If you explicitly share a file for support, it is used to address your request.

Polyhedron's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Optional services and sharing

If you choose AI or machine translation in the desktop application, the text and relevant context needed for that request are sent to the provider you select, using your credentials. Depending on the feature, context may include nearby strings, terminology or translation instructions. Providers can include OpenAI, Anthropic, Google/Gemini, xAI and DeepL. Their terms, retention practices and charges apply; review them before submitting confidential material.

Google receives files you upload to Drive. Reference pages, GitHub release checks, and links to GitHub, Patreon or Ko-fi communicate with those services when used. Third-party services have their own policies. Sharing an export or attaching a project to a public GitHub issue makes its contents available to the recipients or the public.

5. Storage, retention and security

Desktop projects, settings and diagnostic logs are stored on your computer. The browser companion holds workspace data and its access token in the current browser session, and stores preferences and connection-state indicators in browser storage. Cloud copies remain in your Google Drive until you delete them.

Credential protection depends on the version installed. Updated desktop versions use operating-system encryption for saved API keys and Google refresh tokens and exclude credentials from new workspace exports. Older versions and older exports may contain unencrypted credentials. Keep your application up to date and do not share old backups containing secrets.

Network requests to Google and translation providers use HTTPS. No software or storage method can guarantee complete security. Local files are not automatically deleted when you disconnect Drive, clear browser preferences, or uninstall the desktop application.

6. Your choices and deletion

  • Use local desktop editing without connecting Drive or configuring a translation provider.
  • Disconnect Drive in the desktop application. To revoke Google's permission, remove Polyhedron from your Google account's third-party connections. Disconnecting locally is not the same as revoking access at Google.
  • Delete cloud workspace, sync and glossary files from your own Drive, and empty its Trash if you want them removed permanently.
  • Delete local project files, backups, logs and application data separately. Clear this site's browser storage to remove saved browser preferences; close the companion tab to discard its in-memory session.
  • Revoke or replace provider API keys through the relevant provider. If you shared an old backup containing keys, rotate those keys.

For questions or requests concerning information you sent directly to the maintainer, contact the email below. Deletion of data controlled by Google, GitHub or another provider must also be handled through that service.

7. Contact and policy changes

Questions about privacy? Email gabrielbundea1@gmail.com. This policy may be updated as Polyhedron changes; the date above identifies the current version. Material changes to Google data use will be disclosed before that new use, with additional consent where required.
