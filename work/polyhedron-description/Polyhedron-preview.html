Polyhedron brings translation editing, search, review, and export into one workspace for Baldur’s Gate 3, Divinity: Original Sin, and Divinity: Original Sin 2. Spend less time managing files and more time translating.

This is a translation tool, not a finished language pack.

WHAT YOU CAN DO

  • Translate & review — side-by-side or stacked editing, supported gender variants, entry history, review statuses, and formatting-tag helpers.
  • Find what matters — precise search, find & replace, speaker/status filters, repeated-string detection, and content-ID display and copying.
  • Keep wording consistent — compare different translations of identical strings, apply preferred wording, and maintain a glossary.
  • Understand the context — BG3 dialogue references, game data, spells, actions, conditions, and a creature guide with linked translations.
  • Use optional translation providers — Google Translate, DeepL, Gemini, OpenAI, Claude, or Grok; translate individual entries or batches with configurable AI prompts.
  • Export & manage files — XML export, plus supported BG3 PAK/ZIP packaging, extraction, merging, and localization injection.
  • Back up & continue elsewhere — portable .pws workspaces, optional Google Drive synchronization, and a browser/mobile companion for supported editing views.
  • Make it yours — a dark interface with a customizable accent, button text color, and application-icon styles.


Game support: BG3 supports XML/PAK/ZIP workflows and dedicated reference tools. Divinity profiles support localization XML editing and export. Packaging, extraction, and injection remain desktop features.

Online translation is optional and requires your own credentials where applicable. Provider charges are separate; always review generated text before using it in-game.



GET STARTED

  1. Download the appropriate version from Files. On Windows, run the installer. On macOS, open the DMG and drag Polyhedron.app into Applications.
  2. Launch Polyhedron, choose your game and language pair, then create or select a project.
  3. Open your localization file and start translating. To restore an existing workspace, use Workspace → Import Workspace.


Polyhedron is a standalone application: do not install it through Vortex or place it in the game’s Mods folder. You do not need the game installed just to edit a localization file.

Before BG3 injection: close the game and keep your own project and game-file backups. Injection modifies the game’s localization files; updates or file verification may restore the originals.

Workspace import replaces your current workspace; it does not merge it. Local editing requires no Google account. Drive synchronization and online providers require an internet connection.
